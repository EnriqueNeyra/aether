Quick Start Guide

Meet Aether.

Your open-source and local-only indoor air quality monitor.

1. Power It On

Connect Aether to power using a USB-C cable. Once plugged in, the e-paper display will initialize and show the Aether logo before jumping into the main dashboard.

Note: The display may flicker black and white during boot. This is completely normal for e-paper screens as they clear residual ghosting.

2. Connect to Wi-Fi

Connecting to Wi-Fi allows you to access the device's local Web UI to view live metrics, connect to Home Assistant, and receive OTA updates.

  1. Open the Wi-Fi settings on your phone or computer.
  2. Look for a network starting with aether- (e.g., aether-a1b2c3).
  3. Connect to it. A setup portal should automatically open.
  4. Select your home Wi-Fi network and enter the password.

If you set it up from Home Assistant over Bluetooth instead, press the side button once when asked.

Note: The setup network stays on for 10 minutes after power-up. If Wi-Fi isn't configured by then, Aether keeps working offline. To bring the setup network back, hold the side button for 3 seconds on the Device Information screen (this reboots the device), or unplug it and plug it back in.

3. The Display & Metrics

Aether tracks 9 different environmental metrics. The sensor takes a new reading and the e-paper screen refreshes every 5 seconds.

CO2
Carbon Dioxide
Indicates indoor ventilation quality.
VOC
Volatile Organic Compounds
Gases from cleaners, paints, and furniture.
NOx
Nitrogen Oxides
Pollution often from gas stoves or traffic.
PM
Particulate Matter (1.0 - 10)
Dust, smoke, and airborne particles.
Temp
Temperature
Indoor ambient temperature.
RH
Relative Humidity
Indoor moisture levels.

4. Button Controls

The physical side button on the device controls display modes and resets.

  • Short Press

    Device Information

    Toggles the Info screen, which displays the device's hostname and IP address, and QR codes for the instruction manual and local web dashboard. Press again to return to the dashboard.

  • Long Press (3s+)

    Restart Setup Network

    On the Device Information screen, while Aether isn't connected to Wi-Fi, hold for 3 seconds to reboot the device and turn the setup network back on.

  • Long Press (3s+)

    Factory Reset

    From the dashboard, hold for 3 seconds to initiate a factory reset, then hold again for 3s to confirm. Press once to cancel; if you don't confirm within 30 seconds, the reset is cancelled automatically.

5. The Web UI

Once connected to Wi-Fi, Aether hosts a responsive web interface on your local network. You can use it to:

  • View real-time sensor metrics
  • Change temperature units (°F / °C)
  • Check firmware versions and perform OTA updates

Access it by navigating to your device's hostname (e.g., aether-a1b2c3.local) or IP address in your browser. Both can be found on the 'Device Information' screen.

6. Home Assistant

Because Aether runs ESPHome, it features a native API over Wi-Fi. Aether will automatically appear in your Home Assistant integrations dashboard once connected to your network. It exposes all 9 sensor metrics (CO2, temperature, humidity, PM1.0, PM2.5, PM4.0, PM10, VOC index, and NOx index) right out of the box.

Need Help?

Most problems can be fixed by reinstalling the firmware over USB. Connect Aether to a computer, open the Firmware & Updates tab above, and click Install Aether firmware:

  • If the device is stuck in a boot loop or isn't running Aether firmware, the flasher erases it and installs a fresh image.
  • If it's running an older version of Aether, you'll be offered Update, which keeps your settings.
  • If it's already on the latest version, the menu offers Erase User Data to wipe its settings.

To factory reset without a computer, hold the side button for 3 seconds, then hold it for 3 seconds again to confirm.

For full documentation, advanced configuration, or to report an issue, please visit the Aether GitHub Repository.
