Quick Start Guide

Meet Aether.

Your beautiful, open-source indoor air quality monitor.

1. Power It On

Connect Aether to power using a USB-C cable. Once plugged in, the e-paper display will initialize and show the Aether logo before jumping into the main dashboard.

Note: The display may flicker black and white during boot. This is completely normal for e-paper screens as they clear residual ghosting.

2. Connect to Wi-Fi

Connecting to Wi-Fi allows you to access the Web UI, view live charts, change settings, and receive over-the-air updates.

Option A: Mobile Setup

  1. Open the Wi-Fi settings on your phone or computer.
  2. Look for a network starting with aether- (e.g., aether-a1b2c3).
  3. Connect to it. A setup portal should automatically open.
  4. Select your home Wi-Fi network and enter the password.

Option B: WebUSB Setup

  1. Connect Aether to your computer via USB-C.
  2. Switch to the Firmware & Setup tab at the top of this page.
  3. Use the WebUSB tool to securely configure Wi-Fi credentials or update firmware.

3. The Display & Metrics

Aether tracks 9 different environmental metrics. The e-paper screen updates every 500ms when data changes.

CO2
Carbon Dioxide
Indicates indoor ventilation quality.
VOC
Volatile Organic Compounds
Gases from cleaners, paints, and furniture.
NOx
Nitrogen Oxides
Pollution often from gas stoves or traffic.
PM
Particulate Matter (1.0 - 10)
Dust, smoke, and airborne particles.
Temp
Temperature
Indoor ambient temperature.
RH
Relative Humidity
Indoor moisture levels.

4. Button Controls

The physical button on the back of the device controls display modes and resets.

  • Short Press

    Toggle Display Mode

    Switches between the main dashboard and the Device Information / QR Code screen.

  • Long Press (3s+)

    Factory Reset / Reboot

    Hold for 3 seconds to initiate a factory reset (clears Wi-Fi credentials). If on the Info screen and offline, it will simply reboot the device.

5. The Web UI

Once connected to Wi-Fi, Aether hosts a beautiful, responsive web interface on your local network. You can use it to:

  • View real-time sensor metrics
  • Change temperature units (°F / °C)
  • Check firmware versions and perform OTA updates

Access it by navigating to your device's IP address or by trying http://aether.local in your browser.

Need Help?

If you encounter any issues, you can reset the device by holding the back button for 3 seconds.

For full documentation, advanced configuration, or to report an issue, please visit the Aether GitHub Repository.

Desktop Browser Required

WebUSB flashing is not supported on mobile devices. To configure Wi-Fi via USB or update firmware, please visit this page on a desktop Chrome or Edge browser.
